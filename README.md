# 🚨 RAKSHAK — AI-Powered Disaster Response Intelligence

### 🛡️ Detect. Track. Prioritize. Rescue.

**RAKSHAK** is an AI-powered disaster-response intelligence system designed to transform visual data from drones and ground robots into actionable insights for search-and-rescue operations.

By combining computer vision, multi-object tracking, hazard detection, risk assessment, and situational visualization, RAKSHAK aims to help emergency responders identify survivors, understand surrounding dangers, and make faster, more informed decisions during disaster scenarios.

> 🌍 **Our mission:** Turn fragmented disaster-site observations into structured, survivor-centric intelligence that helps responders make every second count.

---

## ⚡ The Big Idea

Disaster zones are chaotic. Survivors may be difficult to locate, hazards can threaten rescue teams, and information from multiple observation points can be difficult to interpret quickly.

RAKSHAK aims to bridge that gap.

Instead of treating object detection as the final result, RAKSHAK focuses on the bigger picture: **understanding what is happening, where attention is needed, and who may require urgent assistance.**

🎯 **The RAKSHAK pipeline:**

`Observe → Detect → Track → Assess Risk → Prioritize → Visualize`

## 🚀 Core Capabilities

### 🧍 1. AI-Based Survivor Detection

Uses YOLO-based computer vision to identify people in visual feeds.

- Detects people in supported image and video inputs.
- Displays bounding boxes and detection confidence.
- Provides a foundation for identifying potential survivors.
- Designed for future integration with aerial and ground-based observation systems.

### 🎯 2. Multi-Object Tracking

Integrates ByteTrack to associate detections across video frames.

- Maintains track IDs for detected objects.
- Helps distinguish persistent tracks from new detections.
- Supports temporal observation instead of relying exclusively on individual frames.
- Establishes a foundation for monitoring survivor movement.

*Tracking IDs do not establish a person's real-world identity.*

### 🔥 3. Fire and Smoke Detection

Uses a YOLO-World-based model configuration to detect fire- and smoke-related visual indicators.

- Identifies potential fire and smoke hazards in supported video inputs.
- Displays detected hazards for situational awareness.
- Provides information that can contribute to risk assessment.
- Creates a foundation for associating hazards with nearby survivors.

Detection accuracy depends on image quality, lighting, visibility, model configuration, and environmental conditions.

### ⚠️ 4. Risk Assessment

RAKSHAK includes an initial risk-assessment layer intended to transform detections into more useful rescue intelligence.

Rather than displaying detections alone, the system is designed to support questions such as:

- Is a potential survivor close to a detected hazard?
- Which observations may require immediate attention?
- Where should a responder investigate first?

The current risk logic is a prototype, not a validated emergency-response decision system.

### 🖥️ 5. Live Situational Dashboard

The prototype includes a desktop dashboard for viewing and interpreting detection results.

- Visualizes detection and tracking information.
- Displays supported hazard information.
- Presents risk-related information generated by the prototype.
- Provides a foundation for a unified search-and-rescue interface.

### 🗺️ 6. Mapping and Spatial Awareness

RAKSHAK includes map-visualization work intended to make rescue information easier to interpret spatially.

Future development aims to connect observations to reliable geographic coordinates, enabling responders to understand where assistance may be needed.

**Important:** A map visualization is not the same as verified survivor geolocation. Accurate positioning requires suitable location data, sensor integration, and validation.

## ⚙️ Getting Started

### Prerequisites

- Python 3.10 or later, subject to dependency compatibility
- Git
- A Windows, Linux, or macOS development environment
- Internet access for initial dependency and model downloads
- A compatible video or image input for testing

A GPU is optional for development, although supported GPU hardware can improve inference performance.

### 1. Clone the repository

Replace `YOUR_USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR_USERNAME/RAKSHAK.git
cd RAKSHAK
```

### 2. Create a virtual environment

**Windows — PowerShell**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can use Command Prompt instead:

```bat
.venv\Scripts\activate.bat
```

**Linux / macOS**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

If the repository contains a `requirements.txt` file:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If it does not, install dependencies according to the actual modules used by your current source code. Avoid installing a generic dependency list that may conflict with your working environment.

### 4. Run the application

Run the entry-point script used by your repository. For example, if the main file is `main.py`:

```bash
python main.py
```

> **Note:** The entry-point filename and exact setup commands must match the files in the repository. Model weights may download automatically or may need to be provided separately, depending on the implementation.

## 📊 How RAKSHAK Should Be Evaluated

A rescue-support system needs more than a convincing demo. Its performance should be measured systematically.

| Evaluation area | Useful metrics |
|---|---|
| Person detection | Precision, recall, mAP |
| Hazard detection | Per-class precision and recall |
| Object tracking | IDF1, HOTA, identity switches |
| Runtime performance | FPS, inference latency, memory usage |
| Localization | Position error and uncertainty |
| Risk assessment | Agreement with expert-reviewed scenarios |
| Operational resilience | Recovery behavior during input or connectivity loss |

Results should be reported only after measurement on a defined dataset or test scenario. No performance figures are claimed here.

## 🔒 Safety, Limitations, and Responsible Use

RAKSHAK is a developing research and prototype project.

- AI detections may be incorrect or incomplete.
- Smoke, dust, darkness, occlusion, and poor image quality can reduce reliability.
- A detected person is not automatically a confirmed survivor.
- Visual proximity does not establish a verified physical distance or hazard exposure.
- Map displays must not be treated as accurate geolocation without validated coordinate sources.
- Risk scores must not independently determine real rescue priorities.
- Critical decisions require trained human responders and appropriate operational procedures.

RAKSHAK is intended to support human situational awareness, not replace emergency professionals or certified safety systems.
